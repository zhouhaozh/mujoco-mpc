## 界面代表什么

- 左侧：最后成功交给 SDK 的五轴目标 `q_ref` 在 MuJoCo 模型中的姿态。
- 右侧：SDK 关节反馈 `q_fb` 在相同 MuJoCo 模型中的姿态。硬件模式明确标识 `REAL HARDWARE`；sim 标识 `SDK SIMULATION`。
- 下方：五轴目标角、反馈角和 `反馈−目标`，显示单位为度，数据采用 SDK 模型角。
- 两侧调用 `mj_forward` 重建几何、底盘固定；**没有运行独立的 MuJoCo 动力学响应**。这适用于关节顺序、方向和姿态对照，不作为重力、惯量、跟踪精度或 MPC 实时闭环验收。
- 默认 SDK J1–J5 与 MuJoCo Joint1–Joint5 同名对应是未标定候选。SDK 已做电机方向/偏移转换，不能再机械重复套用 SDK 的 sign/offset。

可用 `--mapping /绝对路径/mapping.json` 显式提供仅影响显示的候选映射：

```json
{"permutation":[1,2,3,4,5],"sign":[1,1,1,1,1],"offset_rad":[0,0,0,0,0]}
```

定义为 `q_mj[i] = sign[i] * q_sdk[permutation[i]-1] + offset_rad[i]`。映射不改实际控制。左右共同使用此映射，因此“左右一致”不能证明物理轴方向正确，仍须现场观察。完整零位、轴线和末端 FK 标定是后续工作。
