## 1. nmpc6:联合 NLP

### 1.1 变量与参数(生成码契约,`gen_nlp.cc`)

- **状态 14**:[x, y, θ₁..θ₅, vx, vy, ω₁..ω₅](位置 m/rad + 速度 m/s / rad/s,世界系)
- **决策 21** = 3 步 × 7 控制 U=[dvx, dvy, dω₁..dω₅] —— **速度增量**(不是加速度),
  块序布局 [dvx×3, dvy×3, …, dω₅×3]
- **参数 27**:状态 14 + 目标 3 + dt 3 + w_y + hit_spd + hit_z + hit_pitch + hit_yaw
  + plat_vx 开关 + 低球 vy 偏置
- **约束 87 行**(见 1.4)

### 1.2 动力学(梯形积分 + 刹车距离修正)

每步(dt = 剩余/3,三步共用单一 dt):

```
pos⁺ = pos + (v + U)·dt − U|U|/2 · (1/a_max)      v⁺ = v + U
```

第二项是"本步速度增量对应的刹车距离"修正——物理含义:指令改速度后,
按最大减速能力提前折算停止位置。速度增量的量纲是 m/s(不是 m/s²),
所以加速度约束单列(1.4 第 5 块)。ACC 表(m/s², rad/s²):
`a_max = [8, 8, 30, 30, 180, 400, 200]`。

### 1.3 代价 —— **终端唯一**(只在第 3 步末评价,无路径项)

```
J = 1000·(1 − |n·d̂|)                  拍面法向对准出球方向 d̂=(cosβcosγ, cosβsinγ, sinβ)
  + 2500·‖p_racket − p_target‖²        拍心到击球点
  + 8·(hit_spd − v_x)²                 拍速 x 分量(出球速度主项)
  + 0.5·(v_yref − v_y)²                v_yref = tan(γ)·hit_spd + 低球偏置
  + 2·(hit_z − v_z)²                   拍速 z 分量
  + 1.7·(vx² + vy²)                    终端底盘速度罚(挥拍时底盘应基本停稳)
  + Σ_k 控制量小罚                     (1e-5, w_y, 0.1, 0.5, 0.1, 0.1, 0.5)·U²
```

末端位置/速度/法向由解析 FK(闭式 5 旋转链,与 MuJoCo 验证 5.9e-7)+ 符号
jacobian 出;底盘速度按 plat_vx 开关(hit_spd≤28 时)计入拍速。

### 1.4 约束(87 行 = 六块 × 3 步)

| 块 | 行数 | 内容 |
|---|---|---|
| 刹车位置 | 3×7 | X+smooth_fmin(1+A)·ΔX+smooth_fmax(−A)·Fv·M2(平滑 sign/fmax,eps=1e-4)——限"刹车后位置" |
| 步末位置 | 3×7 | x∈[−1,5.7], y∈[−2,2](半场);θ 走**动态角窗**(驱动层逐拍更新,见 1.6) |
| 底盘速度 | 3×2 | ±4 m/s |
| 关节速度 | 3×5 | 正常球 ±[10,10,20,48,15] rad/s;前场球 ±[10,10,40,48,15] |
| 加速度 | 3×7 | ‖U‖ ≤ a_max·dt(平滑 sqrt(U²+ε)) |
| 自碰 | 3×1 | 末端 FK z ≥ 0.35(挥拍不打机器/地面) |

决策界 lbx:增量 ±[4,4,5,3,40,50,10]。

### 1.5 求解(CasADi codegen + IPOPT)

- 离线:`gen_nlp.cc` 用 CasADi 3.7 符号构型 → `generate_dependencies("nlp.c")`
  → gcc 编成 nlp.so(f/g/梯度/雅可比/黑塞**全静态编入**,ldd 仅 libm/libc)
- 在线:`casadi::nlpsol("ipopt")` 动态加载;mumps 线性求解器;max_iter 270;
  mu 自适应等一整组 IPOPT 实机调参(`legacy_nmpc.cpp` 构造函数)
- **热启动**:guess = 上一接受解(回合首解冷,10-30ms;热解 4-5ms)

### 1.6 驱动层守门链(实机验证顺序,移植全保留)

新回合检测(全零 guess)→ 误差补偿注入(ONNX 网,sim 置零;剩余≤50ms 锁存)
→ 冻结窗(剩余>1s 且 J4/J5 静止 → 首步增量零)→ 击球分型(前场/正常,**动态
角窗** m1..m5:如正常球 θ₂∈[10°,60°],m3∈[−144°,0°])→ IPOPT → 数值 rollout
→ 1ms 自碰复检 → 跳变守门(vs 上接受解 m1>60°/m3>50°/m4>90°)→ 角窗+10° 守门
→ 精度双档(严格:三轴<0.05m 且 |vx|>0.6·hit_spd;宽松:三轴<0.20m 且求解成功)
→ 接受(拍心误差反馈到底盘 x/y;首个严格解收紧 m5 窗)。

### 1.7 执行(Plans 语义)

接受解 → 控制增量累积出逐步目标速度 → 从实测速度按 a_max 限幅斜坡、位置
欧拉积分,产出 **1ms 网格执行轨迹**(robot_motion.cc 口径);下位机按剩余时间
索引消费。sim 侧:m2_intercept 绝对时刻采样,底盘=速度直下(伺服 8 m/s² 斜坡
同款),臂=位置+速度参考 hybrid。

## 2. pfly(B′):三级分解

> B′ 不是单一优化问题:只有**臂层是在线优化(QP)**;底盘是解析参考+跟踪;
> 协调契约由上游规划器一次性签发。这就是"联合优化的协调分解"。

### 2.0 上游:HitPlanner(`hit_planner.h`,非优化——采样+评分)

- 从球预测器沿轨迹采样候选 (P_hit, t*),评分 = 可达性 + 时间裕度 + 击球
  高度区;输出:
  - `base_target`:拍心落点的 **IK 可达环带**(0.4-1.1m 臂距)投影——保证臂
    工作空间几何一致
  - `v_racket, n_face`:**反弹逆解**——由意图出球 (8 m/s, 仰角 15°) 经已知
    碰撞模型(解析冲量,k=0.5)反解所需拍速矢量与拍面法向
  - `v_base_star`:fly-through 终端速度意图——沿接近方向投影 v*_xy,
    **投影≤0 则不飞**(底盘贡献为负不如不做,诚实分解)
  - `base_pred`:预测实际底盘位姿@t_hit(P 控误差动力学)——**臂终值按它解**
    而非规划锚(底盘实际滞后 0.1-0.2m 不补则面内 miss 0.16-0.47)

### 2.1 底盘:BaseRefGen 解析参考 + P+前馈(无在线优化)

参考是**解析剖面**,绝对时刻锚定(初规划时刻起锚,重解按绝对时刻取值——
每拍重建会"参考回退爬行"):

- **到位即停**:梯形(0.15s 爬升/巡航/0.25s 收敛)
- **fly-through**(v_fly>0):三次 Hermite (0,0)→(1,w),w=v_fly·Ta/D≤2.2
  保单调;过靶后 t_dec=0.4s 线性刹停。起步加速度 (6−2w)·D/Ta²≠0,
  无 smoothstep 的"慢起步"病

跟踪:`cmd = v_ref + 2.5·(p_ref − p)`,世界系→车体系,clamp ±1.5 m/s。
**这一层没有任何在线求解**——可达性/时序可行性由规划器的 t_arrive 与
v_base* 规则保证。

### 2.2 臂:ArmSwing 两阶段(`arm_swing.h`)

**阶段 1(终值解,IK+伪逆)**:
```
q_hit = IK(拍心 = p_hit, 锚 = base_pred)     + J5 对准 n_face
dq_hit = J⁺·(v_racket − v_base*)             ← B′ 差项:臂只出"拍速需求减底盘贡献"
```

**阶段 2(轨迹 QP,codegen `arm_nlp.c`,OSQP,底盘 MPC 同构)**:
- 参数化:每关节 **Chebyshev 样条 5×9 系数**(45 变量),t∈[t₀,t₀+T] 映射
  s∈[0,1],**触球是内点 s_hit=0.72**(其后 28% 为随挥收势——拍在触球带内
  达峰速,不是轨迹终点急刹)
- 约束(全线性):边界 q(0)=q₀, dq(0)=dq₀;**终值内点** q(s_hit)=q_hit,
  dq(s_hit)=dq_hit;末端静止 dq(1)=0;72 条速度限位;系数盒
- 目标:二次(样条平滑项,权重按 s 域标定;FK 残差不进目标——大残差二阶
  项不定,OSQP 拒收,以阶段 1 的 IK 保证)
- 求解毫秒级;**事件驱动重解**:重规划拍更新终值,锁止(t_hit−t<0.15)后
  按 §6.5"冻结大改、仅微调"(逐关节 ≤0.05 rad)——挥拍中途大改必失稳

**播放(1kHz)+ τ̂ 闭环滞后补偿**:指令轨迹与实测的最小二乘时间移位
τ̂=e·dq/‖dq‖²,播放时钟前移 τ̂(拍在 t_hit 实际抵达;常数提前量覆盖不了
高位族的大滞后)。

## 3. 对比与评注(供审阅讨论)

| 维度 | nmpc6 | pfly(B′) |
|---|---|---|
| 建模粒度 | 全机统一动力学,底盘-臂交换在解内 | 契约分解:规划器签发、底盘执行、臂在边界内最优 |
| 问题类别 | NLP(FK 非线性+平滑约束) | 底盘无优化;臂 QP(IK 先解 → 全线性约束) |
| 触球表达 | 终端位形+速度(终点即触球) | **内点**约束(触球在 72%,随挥成形) |
| 底盘-臂速度耦合 | OCP 内(1.7·v² 罚让底盘停稳) | 显式差项 dq=J⁺(v*−v_base*) |
| 可达性 | 角窗+刹车行硬约束(实机风格) | 上游 IK 环带 + v_base* 投影规则 |
| 模型误差处理 | ONNX 误差网(真机)+ 误差反馈项 | τ̂ 在线滞后辨识 + base_pred 外推 |
| 在线成本 | 4-5ms×50Hz(冷解 30ms) | 臂 QP ~ms×事件驱动;底盘 0 |
| 已知短板 | 终端唯一代价→末段速度-位置权衡(挥扫线系统性短左 0.15-0.3,真机靠误差网);角窗为羽毛球标定,sim 真实待机下 0 解 | 无全局最优性(两臂让步类解发现不了);依赖上游契约质量 |

**结构性评注**:nmpc6 把"该怎么挥"全部交给单个 NLP 的权重平衡(位置 2500 vs
速度 8 vs 法向 1000),末段视界收缩时这些权重的相对优先级会漂移——这是
挥扫线短左的根源;B′ 把"挥到哪/多快/什么面"变成**硬边界约束**(IK+内点),
QP 只在剩余自由度里求平滑——约束优先于权重,是其定点族 100% 的结构性原因。
代价是 B′ 的可行性完全依赖上游契约,遇到"必须联合让步"的场景(如臂减速换
底盘更早到位)无能为力——这正是 wbmpc(真联合 OCP)的立项动机。
