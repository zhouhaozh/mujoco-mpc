# 网球环境时间窗口搜索与确认

日期：2026-10-19，北京时间。计算与结果生成全部在 Ubuntu `ubuntu-11 / 172.20.0.11` 执行；Mac 仅编辑源码和本文。分支为 `codex/pipeline-modularization`，未提交、未推送，未替换原默认二进制和模型权重。

本轮在指定范围内完成两轮坐标搜索。冻结候选后，保留的17条历史轨迹确认：**pfly 接近几何触球从8/17升到11/17（47.1%→64.7%，+17.6个百分点）；nmpc6仍为6/17，出现回退的试次从9降到4。** 这些轨迹以前已用于项目研究，确认集只是在本轮未参与选型，不是新盲测；本次结果不证明全局最优。

**独立合成解析碰撞没有复现提升：pfly从18/30降至16/30，nmpc6从7/30降至2/30。** 因此本轮没有得到兼顾两种口径、可直接替换默认的方案。保留原默认；pfly候选只作为历史回放几何指标的探索结果，nmpc6候选虽减少回退，也不建议默认启用。

## 三段和各时间窗口的实际含义

nmpc6 的三段是同一最优控制问题的三个离散区间，每次求解按剩余触球时间 `T=t_hit−t_now` 重算，原来各为 `T/3`。三节点均推进同一组14态、7控制，终点就是触球时刻；源码没有将它们标为准备、击球、随挥，触球后随挥也不在这三段内。羽毛球工程来源不能直接证明等分比例适合网球。

三段比例会改变第一节点可用行程、节点间加速度和沿途约束，因此会影响可行性和触球。J4/J5冻结窗、末段严格接纳窗、停止重解窗，以及pfly准备/锁定窗，是另外的时间策略，须分别记录。

| 参数 | 原基线 | nmpc6冻结候选 | pfly冻结候选 |
|---|---:|---:|---:|
| 未来预测上限 | 1.5s | **1.8s** | **2.0s** |
| 规划最小提前量 | 0.9s | 0.9s | 0.9s |
| 规划最大查询时距 | 2.5s | 2.5s | 2.5s |
| 目标锁定策略参数 | 150ms | 150ms | **200ms** |
| 准备期间允许目标精化 | 否 | 否 | **是** |
| pfly准备时间/准备过渡 | 250ms | 250ms | **350ms** |
| pfly轨迹最短时长 | 300ms | 300ms | **200ms** |
| pfly轨迹最长时长 | 1.8s | 1.8s | 1.8s |
| pfly原先的额外提前补偿 | 20ms | 20ms | **0ms** |
| nmpc6三段比例 | 1/3、1/3、1/3 | **50%、30%、20%** | 不适用 |
| nmpc6冻结/严格/停止窗 | 1s / 100ms / 12ms | 保持 | 不适用 |

表中nmpc6列的pfly参数均保持原值。nmpc6回退会立即初始化ArmSwing，不走pfly准备延迟，也不执行专属准备过渡；ArmSwing的提前补偿、时长和锁定参数仍适用于回退。

锁定参数不是对物理触球时刻的精确倒计时：原pfly使用 `(t_hit−20ms)−t_last_solve<150ms`，约在名义触球前170ms进入该门；候选提前补偿为0、锁定参数200ms，约为200ms，另受50Hz调用量化和最后求解时刻影响。参数是联合筛选的结果，不能把最终增益全部归因于其中一个参数。

## 搜索协议

固定 `M2_CONTROL_VARIANT=baseline`、`M2_STEER_RATE_MODE=both_unlimited`，使用QP挥拍、相同35条原始CSV、相同场景和原模型权重。力矩、转矩转速包络、9ms执行延迟、驱动轮斜坡、出球目标及精度接纳条件均不改。与历史 `limited` 或其他控制变体的命中数不能直接作前后比较。

先固定发现18/确认17的拆分。第一轮26组×18条，搜索提前量、准备时间/精化、冻结/严格/停止窗；第二轮34组×18条，搜索六种预测时距、锁定窗、四种三段比例和pfly时间组合。两轮合计1080次有效发现试验；冻结第二轮候选后，仅基线与候选执行68次确认试验，不再重选。

排序事先固定为：接近几何触球数、几何相交数、较少回退试次、较小最小间隙P95、稳定任务ID。全部样本保留在分母中；无规划算未触球，技术失败不能从分母删除或参与选型。有效两轮发现与确认均无技术失败。

六个预测上限为0.8/1.0/1.2/1.5/1.8/2.0s。每种时距、每条轨迹分别从原始观测前缀运行预测，共210份缓存；没有用截断长缓存冒充重新预测。H1.5的35份缓存与原缓存除耗时字段外数值一致。延长部分沿用原飞行/反弹预测器继续外推，其中反弹仍包含冻结GP映射；0.7s外不使用残差头修正，未扩展该残差头的使用域或重训权重。

非均匀三段需用新生成的独立NLP库；旧库的动力学只读首段dt，直接改数组会造成求解与执行不一致。本轮修改生成动力学以逐段使用dt、开放请求比例并调整走廊时间节点，以库能力标记拒绝不匹配组合；原有加速度约束、数值rollout及1ms轨迹累计边界已经逐段使用dt，本轮复核它们与新库一致。原等分路径保留原 `T/3` 浮点运算；独立模型检查和20组等分目标/约束函数比较通过。

初始设置错误、缺少绘图库导致的旧评分失败均保留在证据根，不计入有效搜索。评分已拆为不依赖绘图库的纯指标模块，无须为实验安装新绘图库。

## 同条件实测轨迹结果

主指标为有限拍面盒与球相交，且相对法向速度满足接近门 `≤−0.30m/s`；按计划触球时刻±0.35s、第二次触地前、1ms插值计数。原参考球回放不因球拍碰撞改变轨迹，因此这是**几何触球比例，含回退，不是实际碰撞或有效出球成功率**。

| 控制器 | 子集 | 原基线 | 冻结候选 | 变化 | 回退试次 |
|---|---|---:|---:|---:|---:|
| pfly | 发现18 | 9/18（50.0%） | 14/18（77.8%） | +27.8个百分点 | 0→0 |
| pfly | 确认17 | 8/17（47.1%） | 11/17（64.7%） | **+17.6个百分点** | 0→0 |
| pfly | 合并35 | 17/35（48.6%） | 25/35（71.4%） | +22.9个百分点 | 0→0 |
| nmpc6 | 发现18 | 9/18（50.0%） | 9/18（50.0%） | 0 | 8→3 |
| nmpc6 | 确认17 | 6/17（35.3%） | 6/17（35.3%） | **0** | 9→4 |
| nmpc6 | 合并35 | 15/35（42.9%） | 15/35（42.9%） | 0 | 17→7 |

合并35包含选型数据，仅作探索描述。单看总数会掩盖新增/丢失样本及回退贡献；配对检验、原生控制贡献与全程复核见下方最终审计。

发现集中的负结果也保留：nmpc6关闭冻结窗为5/18，短预测0.8/1.0/1.2s为2/4/3条；pfly准备时间降到零为2/18。三段50/30/20与60/30/10均为9/18、回退3条；20/30/50与20/40/40分别为7/18、6/18。不能用“全部缩短”作为优化规则。

## 最终审计与独立合成确认

最终复算通过1603份文件的传递SHA256核验，覆盖预测源码/模型包/生产缓存、运行源码/二进制、原始CSV、策略、日志与完成记录。主口径1ms与0.5ms分类完全一致；扩大到已规划全回合记录范围后，所有样本的几何/接近分类也不变，未发现依靠移动评分窗口得到的提升。

pfly确认集新增 `test_10、test_27、test_30`，没有丢失原已触球样本，配对精确双侧McNemar `p=0.25`。合并35新增8条、丢失0条，但其 `p=0.0078125` 包含发现集选型，不能作为独立显著性证据。现有确认样本仍少，不能据此认定对新球路稳定提升。

nmpc6确认集新增 `test_18、test_27、test_32`，丢失 `test_08、test_23、test_31`；合并35新增5、丢失5，总触球比例未提高。触球时由nmpc6原生执行的接近几何数，确认集从3/17到6/17，合并35从9/35到15/35。优化主要减少了回退依赖，并未增加总触球数；原生/非原生归因在同一网格使用完整接近门，不能以原生几何相交代替。

所有组的trace末帧均比第二次触地/输入终点早少于5ms，最大4.8ms。全回合复核只覆盖已记录范围，不外推尾段；未触球表示该范围内未观察到接触。

独立保护审计通过：562项内容保持，21项原文件为明确授权部署，10项为新增部署文件；原默认/旧模块化二进制、模型、原输入及旧缓存未改。当前分支和起点HEAD正确、Git暂存为空。Ubuntu CTest 10/10、旧/新默认实测配对6/6、缓存构造5项、模型包19项、搜索14项、合成零命中处理1项、真实预测集成3项、终审11项、保护审计7项均通过；这些检查各有自己的适用范围，不是硬实时或实机验收。

另行固定四条设置，使用真实在线预测服务与解析地面/拍面冲量仿真，分别运行fixed/rand/gs三球族、种子2026/31、每组5球，共24组/120球。它未用于重选参数；不同球族每个方法各10球，所有未规划/零命中都留在完整30球分母内。

## 文献依据与300Hz边界

[ESTHER网球机器人作者论文](https://bpb-us-e1.wpmucdn.com/sites.gatech.edu/dist/d/958/files/2023/01/zaidi_wtr.pdf)根据预测轨迹、底盘状态、挥拍耗时与到球时间安排拦截，并持续修正；[Koç等在线最优轨迹论文](https://www.ias.informatik.tu-darmstadt.de/uploads/Publications/Online_optimal_trajectory_generation.pdf)研究的是乒乓球，将触球时刻和终端状态联合优化，并扣除实际求解耗时；[Yang等网球视觉预测论文](https://academic.oup.com/jcde/article/10/3/1176/7197436)结合远处提前观测与机器人近处继续修正。这些工作支持按本机运动能力搜索窗口，没有给出可直接移植到本项目的通用最优秒数。

本轮仍是1ms仿真tick、每20tick重规划的同步链；**没有验收目标精化或联合MPC墙钟300Hz**。同35条记录中，nmpc6原基线1424次求解均值7.16ms、P95为17.81ms；候选2168次求解均值6.46ms、P95为15.24ms、最大60.38ms，单求解已经超过3.33ms周期预算。这些是本轮运行耗时分布，不是实时最坏耗时保证；pfly的QP与目标精化未在本轮单独验收300Hz。

300Hz要求完整路径在3.33ms内完成并处理长尾、迟到结果和实际数据年龄；仿真节拍、离线命中比例与物理单步吞吐都不能替代该验收。异步预测/求解和墙钟截止时间改造应在本轮参数证据冻结后独立实施。
