## 在开发Ubuntu操作

```bash
/home/ubuntu/Zhaohui/sim/.venv/bin/python /home/ubuntu/Zhaohui/sim-x4-interface/tools/x4_arm_compare.py --backend hardware --test-mode direction --step-deg 10
```

按终端提示完成认证及仅CAN准备，确认现场条件后手动输入`START-HOME`。等待“已稳定”后：

```text
3
status
+
-
loop 1
```

每条输入后回车并等待上一步稳定；`3`请求选J3，须确认状态显示J3再动作。`+`后需`-`返回原命令目标，才能切轴或启动loop；反馈无需精确回到原角才允许方向测试继续。GUI主键盘或小键盘1–5选轴，L执行3轮，P完成当前往返后暂停。stop结束本轮动作权限，quit正常退出；SDK Stop不是失能。
