## 零点定义(驱动器层面标定;注意坐标系约定)

- J1:大臂朝机器正前方(插销孔位)
- **J2:大臂与地面夹角为零(水平)**
- J3:与大臂夹角 90°(插销孔位)
- J5:球拍垂直于地面
- 舵轮:驱动轮指向**车中心**(与整车朝向成 45°/135°)——与仿真
  `steer_offset_rad`(±45°)一致

### ⚠️ 坐标系注意事项(用户 2026-10-06 指出)

1. **sckd-robot 的待机参数是相对驱动器标定零位的**(如 J2 待机 +0.61 rad =
   相对"大臂水平"零位抬 35°)。仿真模型零位若与标定零位不重合,需零位偏置
   换算(model = f(driver_zero))后才能迁移;URDF J2 限位 [−3.14, 0.5] 与
   待机命令 +0.61 的表面矛盾源于此,待实机核对偏置表。
2. **旧版代码与重构的 sckd-robot 中,机械臂末端坐标系未与底盘坐标系统一**
   (已知问题,后续解决;先调通功能)。
