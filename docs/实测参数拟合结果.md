# 五组实测命令：仅参数拟合结果

本轮已把最优候选应用到当前 X4_950 仿真配置，但**没有全部通过约定阈值**。每组每轴要求角度 RMSE ≤ 5° 且速度 RMSE ≤ 0.5 rad/s；25 个“组别×关节”组合中 19 个通过。第 2、5 组五轴通过，J3/J4 在五组均通过。没有逐轮反馈，不能验证底盘每台电机。

## 约束与方法

沿用同一首帧可观测状态、同一下发命令、原始时间与关节映射、world 底盘命令、混合控制和开启的重力前馈。未修改运行时代码或二进制；没有复制后续实测状态、改写命令、时间平移或逐组使用不同增益。只改固定增益、有效限矩、关节 armature/damping/frictionloss、底盘斜坡与伺服参数。几何、质量、刚体惯量、碰撞、接触参数不变。

使用第 1、3、4 组优化，第 2、5 组验证；验证组未进入优化目标，但经过多轮候选检查，不能视为新的盲测。机械臂已记录 3858 次候选评估，另做 132 次摩擦搜索；底盘 842 次候选评估。搜索含有界最小二乘、差分进化及 Powell 局部优化。J1/J2 强化搜索为 30 代、popsize 10，再分轴搜索；摩擦搜索改善不足 0.33% 且部分轴变差，最终保留 0。搜索次数不是全局最优或不可拟合的证明。

## 剩余差异与证据边界

- J1/J2 的 Kd 已接近协议上限 100。提高限矩后的饱和比例很低，继续加大限矩不是目前主要改善方向。
- 部分记录开始阶段实际角度和位置命令相差很大、位置命令滞留，而速度命令为零；固定混合控制同时满足这些命令与真实响应存在明显折衷。真实控制模式、前馈和记录前控制器历史仍未知。
- 实测角度与速度积分之间存在不一致，J5 速度还含高频起伏。它们可能影响误差下限，但本轮没有证明剩余误差完全来自噪声，也没有证明所有参数组合都不可达标。
- 底盘舵角/轮速按初始车速无滑动重建，斜坡/积分历史未知。拟合可能吸收初始化误差，不能视为真实轮电机参数辨识。
- 现有五段短记录无法验证其他姿态、负载、速度及长时运动。进一步确认全部对齐需要真实驱动模式/Kp/Kd/前馈及统一时间的 q/dq/逐轮反馈；不能靠宣称本轮全部达标补齐缺失证据。
