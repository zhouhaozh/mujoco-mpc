## 0. 前提与现场校核(开工前一次性)

1. **固件**:标准 MIT 帧五字段(pos/vel/kp/kd/**τ_ff**)、无积分项;
   τ 槽量程 RS04 ±120 / RS06 ±36(不符则改 `mit_arm_id.py` 头部 `TMAX`)、
   反馈速度刻度 RS04 ±36 / RS06 ±75(**注意旧仓代码按 ±66 解码——第一件
   核对项**)。**[现场]**
2. **命令延迟实测**:录"发阶跃帧→运动起点"间隔(同底盘 m1_step_resp
   做法),写入每个日志 manifest 的 `delay_ms`。错位 3ms→惯量偏 1–5%,
   9ms 全错→13–150%,不实测后面全白做。**[现场]**
3. **编码器/反馈格式**:位深(仿真按 14bit)、遥测帧率。**[现场]**
4. **装拍状态定死**:装最终拍标定(推荐),或空载标+拍作已知外载——
   全流程一致;拍更换/配重变化>5% 重跑 §1。
5. **角度约定**:所有日志中的关节角一律用 **MJCF/URDF q 系**(q1..q5,
   与 URDF Joint1..5 同零位同正方向)。电机系→q 系的 sign/offset 换算
   在驱动层完成后再记日志(python 的 FK 假设 q 系)。两系 J2 抬臂符号
   相反是已知坑(交接文档 §4.1)。
6. **安全**:J2/J3 软限位余量 0.15–0.2 rad;力矩头寸 0.4×峰值;
   **每帧检查 |τ̂|>0.9×T-N 包络即整段中止**;急停在手;每阶段先单关节
   低增益冒烟 5 s 再放行。

## 0.5 日志规范(真机记录义务,逐列)

**每阶段一个独立 CSV 文件**(主机在该阶段开始时开日志、结束时关),
**250Hz 每发一帧记一行**(=4ms 一行,全部阶段统一;python 重构按此对齐)。
首行之前写 manifest 行(每行一个或多个 `键=值`,以 `# ` 开头):

```
# scenario=poses|constvel|chirp|swing
# delay_ms=9          ← §0.2 实测值(必填,处理端读它)
# frame_ms=4          ← 发帧周期(必填)
# fb_bits=14          ← 编码器位深(选填)
# kp_track=…,…,…,…,…  ← 本阶段实际增益回显(选填,建议)
# date=YYYY-MM-DD     ← 选填
```

**poses / constvel / chirp 文件列(顺序固定;poses 比其余多最后 2 列)**:

| 组 | 列名(×5 关节 j=1..5) | 含义 | 单位 |
|---|---|---|---|
| 时间 | `t` | 本行帧的时刻 | s |
| 参考 | `qref_j*, vref_j*, aref_j*` | 本帧下发的参考位置/速度/加速度 | rad, rad/s, rad/s² |
| 命令回显 | `p_cmd_j*, v_cmd_j*, kp_cmd_j*, kd_cmd_j*, tff_cmd_j*` | 实际量化后发出的帧字段(发什么记什么) | rad / rad·s⁻¹ / — / — / N·m |
| 遥测 | `q_j*, dq_j*` | 本帧收到的反馈(收什么记什么) | rad, rad/s |
| poses 附加 | `settled, pass_dir` | 见下 | 0/1;+1/−1 |

示例行(节选,合成值):
```
12.3360,-0.510000,0.00000,0.0000,…,-0.509775,…,-0.583,…,1,-1
```
- `settled`:主机若算得出就写(判据=过去 300ms 内 max\|dq\|<2e-2 且逐关节
  std(kp·e_p)<0.3 N·m,命中后 0.5s 窗内置 1);**算不出就不写这列**,
  python 自动判稳(已对仿真数据验证:自动 64 配对/留出 0.131 N·m,与
  手工列一致)。
- `pass_dir`:**必写**——当前姿位是正序趋近(+1)还是倒序趋近(−1),
  每姿位一个常量即可(python 靠它做双向配对,无法自动推断)。
- 真值诊断列(tau/grav/Mii)是仿真专属,真机不写。

**swing 验收日志**(关 3 用,两遍各一文件):
`t, qref_j*, vref_j*, aref_j*(16), q_j1..5(5), tff_cmd_j1..5(5)`。
FF-off 遍 tff 全 0,FF-on 遍 tff=部署前馈。处理命令见 §4。

体量预估:poses≈150s×250Hz≈3.8 万行;constvel 64s≈1.6 万;chirp 40s≈1 万;
两遍 swing 各 4s≈1000。
