# 实时预测与挥拍示例

完成项目环境安装和构建后，在工程根目录运行：

```bash
bash tools/run_trajectory_live.sh
```

默认使用 `synthetic_trajectory.csv`，在 MuJoCo 中实时显示预测轨迹、
规划击球点和机器人动作。默认循环重新计算；加 `--once` 运行一轮后保持画面。

该文件是合成数据：使用工程的 BallServer、无旋气动模型和地面冲量生成，
起点 `(4.8, -0.5, 3.0) m`，初速 `4.5 m/s`，仰角 `40°`，方位角 `185°`。
共 161 帧、采样率 100 Hz、时长 1.6 s；表头为 `t_s,x_m,y_m,z_m`。
CSV 参考回放不施加击球冲量，不能用于物理出球命中率或实机验收。
